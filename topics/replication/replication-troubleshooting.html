Replication Troubleshooting Guide

Use this guide to diagnose and resolve common data replication issues.

Common Issues and Solutions

The following table lists common error codes and recommended resolution actions.

Error Code Cause Resolution
ERR_REPL_TIMEOUT Network latency exceeded connection timeout limit. Increase the timeout threshold under Replication Settings.
ERR_TARGET_FULL Secondary target storage lacks sufficient free capacity. Expand target volume or apply retention cleanup rules.

Verify Target Connectivity

  1. Open a terminal session on the source appliance.
  2. Run the diagnostic ping command to test the target destination endpoint.
  3. Inspect replication log files for active session warnings.
