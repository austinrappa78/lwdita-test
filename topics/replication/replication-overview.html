Data Replication Overview

Data replication enables continuous synchronization of backup storage across secondary sites and cloud storage targets.

Replication Modes

Select a replication mode that matches your recovery point objectives (RPO) and network bandwidth availability.

The following table lists the supported replication modes and their operational parameters.

Replication Mode Description RPO Impact
Synchronous Writes backup snapshots concurrently to primary and secondary sites. Zero RPO
Asynchronous Transfers backup snapshots periodically based on a configured interval. Interval-based RPO

Platform Compatibility

Cloud replication automatically handles bandwidth throttling and target storage provisioning.

On-premises replication requires explicit target storage path configuration.
